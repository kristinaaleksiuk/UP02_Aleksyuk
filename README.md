# УП.02.01 — Продажа велосипедов (ООО «ВелосипедДрайв»)
**Автор:** Алексюк Кристина Николаевна · **Преподаватель:** Аксёнова Т.Г.

## Структура
- `db/schema.sql` — создание БД BikeShop (SQL Server, 3НФ)
- `db/data.sql` — очищенные данные из Excel
- `db/backup.sql` — резервное копирование / восстановление
- `BikeShopApp/` — WPF-приложение (.NET Framework 4.8, ADO.NET)
- `docs/` — ERD, нормализация, диаграмма прецедентов, чек-лист критериев
- `images/` — логотип, иконка, picture.png, фото товаров

## Запуск
1. SSMS: выполнить `db/schema.sql`, затем `db/data.sql` (нужен SQL Server 2017+ из-за STRING_AGG).
2. Открыть `BikeShopApp/BikeShopApp.csproj` в Visual Studio 2022, при необходимости поменять `Db.ConnectionString`.
3. Положить `logo.png` и `icon.ico` в `images/`, запустить.

## Роли
Гость и клиент — просмотр товаров; менеджер — поиск/сортировка/фильтр + просмотр заказов; администратор — полный CRUD товаров и заказов.
